# Contribution Playground — 练手沙盒

<p align="center">
  <strong>CUMT Alethic Insight Lab</strong>
  <br />
  A safe, non-sensitive sandbox for practicing the GitHub contribution workflow.
  <br />
  一个安全、非敏感的练手沙盒,用来练习 GitHub 协作流程。
</p>

---

This repository exists so new members can practice **Issues, branches, Pull Requests, and reviews** without touching real project code. Everything here is repeatable: finish a task once, then do it again in a fresh branch.

本仓库用于让新成员练习 **Issue、分支、Pull Request 与评审**,不影响任何真实项目。所有任务都可以重复做:做完一次,开个新分支再来一遍。

## Tasks — 任务清单

| # | Task | 任务 | What you practice | 练什么 |
| --- | --- | --- | --- | --- |
| 01 | [First Pull Request](tasks/01-first-pr.md) | [第一个 PR](tasks/01-first-pr.md) | Fork/branch, edit, commit, open PR | Fork/分支、修改、提交、发起 PR |
| 02 | [Add a Test](tasks/02-add-test.md) | [补一个测试](tasks/02-add-test.md) | Writing and running tests | 编写并运行测试 |
| 03 | [Review Others](tasks/03-review-others.md) | [评审他人 PR](tasks/03-review-others.md) | Reading diffs, leaving review comments | 阅读 diff、撰写评审意见 |

Suggested order: 01 → 02 → 03, but any order works.

建议按 01 → 02 → 03 的顺序完成,不按顺序也可以。

## Ground Rules — 基本规则

| Rule | 规则 |
| --- | --- |
| Non-sensitive content only | 只放非敏感内容 |
| No real personal data (names, student IDs, contact lists) | 不写真实考生数据(姓名、学号、联系方式等) |
| No credentials, tokens, passwords, or server details | 不写任何密钥、密码、token 或服务器运维细节 |
| No QQ group numbers or QR codes | 不写 QQ 群号或二维码 |
| Small, focused changes; one task per PR | 改动小而专注,一个任务一个 PR |
| Tasks are repeatable — use a fresh branch each time | 任务可重复做,每次开新分支 |

## AI Assistance — AI 辅助

AI assistance is allowed. Blind submission is not. Disclose the tool you used, which parts it wrote, and how you verified the result.

允许使用 AI 辅助,但不允许不加核实地直接提交。请说明用了什么工具、它生成了哪些部分、以及你如何验证结果。
