# Task 01 — First Pull Request / 第一个 PR

Fix a typo or wording issue in this repository and open your first Pull Request.

修正本仓库中的一处错字或措辞问题,并发起你的第一个 Pull Request。

## Goal — 目标

Complete the full contribution loop once: fork or branch → edit → commit → PR → merge.

完整走一遍协作闭环:fork 或开分支 → 修改 → 提交 → PR → 合并。

## Steps — 步骤

1. Find a typo or awkward sentence in any doc file (`README.md` or anything under `tasks/`).
   This file itself contains one on purpose: the word "excersise" below is misspelled.
   If someone already fixed it, pick any other wording issue you can find — the task stays repeatable.

   在任意文档文件(`README.md` 或 `tasks/` 下的文件)中找到一处错字或不通顺的句子。
   本文件故意留了一处:下面的单词 "excersise" 拼写错误。
   如果已被人修掉,另找一处措辞问题即可——任务可重复做。

   > This excersise is intentionally seeded here for practice.

2. Create a branch named like `fix/typo-<your-github-id>`.

   新建分支,命名为 `fix/typo-<你的 GitHub ID>` 之类的形式。

3. Make the smallest possible fix and commit with a message like `docs: fix typo in task 01`.

   做最小改动,提交信息示例:`docs: 修正任务 01 中的错字`。

4. Open a Pull Request against `main`. Fill in the PR template: what changed, why, and how you checked it.

   向 `main` 分支发起 PR,按模板写清楚:改了什么、为什么、如何验证。

5. Wait for review, respond to comments, and merge after approval.

   等待评审,回复评论,通过后合并。

## Done When — 完成标准

| Check | 检查项 |
| --- | --- |
| PR is opened from your own branch | PR 从你自己的分支发起 |
| Diff contains only the intended fix | diff 中只包含目标修改 |
| PR description explains the change | PR 描述说明了改动 |
| PR is merged after review | 评审通过后合并 |
